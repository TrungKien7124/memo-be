TÀI LIỆU PHÂN TÍCH, THIẾT KẾ HỆ THỐNG & BACKEND - MEMO

1) TỔNG QUAN DỰ ÁN
- MEMO là nền tảng học tiếng Anh tích hợp AI, tập trung vào ghi nhớ dài hạn và luyện giao tiếp.
- Mục tiêu:
  - Học tiếng Anh theo khóa học có cấu trúc.
  - Ghi nhớ hiệu quả bằng Flashcard + Spaced Repetition.
  - Đánh giá học tập dựa trên thời gian học thực tế.
  - Luyện nói bằng AI hội thoại hai chiều.
  - Thiết kế theo hướng data-driven, sẵn sàng cho ML.
- Quy mô: đồ án cá nhân, < 1.000 người dùng.

2) PHẠM VI CHỨC NĂNG CHÍNH
2.1 Quản lý khóa học
- Người dùng chọn khóa học và xác nhận tham gia.
- Video bài học nhúng từ YouTube/Vimeo.
- Cần xem tối thiểu 2 phút để tính hoàn thành.
- Hoàn thành lesson/ôn tập/quiz được cộng XP.
- Trang xác nhận khóa học thiết kế để mở rộng thành payment sau này (hiện chưa xử lý).

2.2 Flashcard và Folder
- Người dùng tự tạo folder (không lồng nhau).
- Mỗi flashcard thuộc 1 folder.
- Flashcard hỗ trợ: từ/câu, nghĩa Việt, IPA, audio, hình, loại thẻ.

2.3 Ôn tập + Spaced Repetition
- Mục tiêu học: số phút học mỗi ngày (minutes per day).
- Thời gian học được đo khi người dùng ở trong web và có tương tác.
- Card mới chỉ xuất hiện ở session sau, không xuất hiện trong session hiện tại.
- Card đã học trong session không lặp lại.
- Học hết card -> kết thúc session.
- Thuật toán:
  - EASY: tăng stage, tăng interval (3, 7, 30, ... ngày).
  - HARD: reset stage, ôn lại ngày hôm sau.
  - Stage/interval không giới hạn cứng, có thể điều chỉnh bởi ML.

2.4 Luyện nói AI
- AI và người dùng hội thoại 2 chiều, không kịch bản cứng.
- Có template chủ đề để AI dẫn dắt.
- AI thích nghi theo câu trả lời.
- Chỉ feedback bằng text, không chấm điểm.
- XP cho speaking cao hơn các hoạt động khác.

2.5 Gamification
- XP cộng theo: hoàn thành video, ôn tập, quiz, speaking.
- Leaderboard theo XP và thời gian học.

3) KIẾN TRÚC HỆ THỐNG (SYSTEM DESIGN)
- Modular Monolith, tách thành 3 app để dễ tách service sau này:
  - app_server: IAM/CMS/LMS/NFS/SOC/GMS/NTS/ADM
  - srs: SRS/RSE
  - ai: ACS/SPS
- Core dùng chung nằm trong app_server (base controller/serializer/normalizer/validator/pagination/exceptions).
- Data-driven: lưu log học tập, SRS state, review log để sẵn sàng ML.

4) CÔNG NGHỆ SỬ DỤNG
- Frontend: ReactJS
- Backend: Django + Django REST Framework
- DB: PostgreSQL
- Cache/Queue: Redis
- Async jobs: Celery
- Realtime: Django Channels
- AI: RAG, STT, TTS

6) THIẾT KẾ BACKEND CHI TIẾT (CODEBASE HIỆN TẠI)
6.1 Nguyên tắc thiết kế
- Modular Monolith, tách thành 3 app để dễ deploy độc lập.
- Core dùng chung đặt trong app_server để không rời rạc.
- API layer mỏng, chuẩn hóa input/output, ưu tiên tách service/usecase khi nghiệp vụ phức tạp.

6.2 Cấu trúc thư mục
- memo_backend/
  - settings.py: cấu hình Django/DRF/CORS/Channels/Celery, auth model.
  - urls.py: router gốc.
  - asgi.py, wsgi.py: entrypoints.
  - routing.py: websocket routes placeholder.
  - celery.py: cấu hình Celery.
- apps/app_server/
  - controllers/{base,implemented,extended}
  - models/{base,implemented,extended}
  - serializers/{base,implemented,extended}
  - normalizers/{base,implemented,extended}
  - validators/{base,implemented,extended}
  - routes/{base,implemented,extended}
  - pagination/base
  - exceptions/base
  - management/commands/seed_demo.py
- apps/srs/
  - controllers/{base,implemented,extended}
  - models/{base,implemented,extended}
  - serializers/{base,implemented,extended}
  - normalizers/{base,implemented,extended}
  - routes/{base,implemented,extended}
- apps/ai/
  - controllers/{base,implemented,extended}
  - models/{base,implemented,extended}
  - routes/{base,implemented,extended}

6.3 Quy ước đặt tên file
- Model: <domain>_<entity>_model.py (vd: iam_user_model.py, srs_card_srs_state_model.py)
- Controller: <domain>_<entity>_controller.py
- Serializer: <domain>_<entity>_serializer.py
- Normalizer: <domain>_<entity>_normalizer.py
- Route: <domain>_route.py
- Base: app_server_base_*.py

6.4 Vai trò các lớp chính
- BaseModel: khai báo model dùng chung (abstract).
- CoreModelViewSet: CRUD cơ bản, hỗ trợ input normalizer.
- CoreModelSerializer: cấu hình field_list, ignore_fields, validation_rules.
- Normalizer: nhận data thô từ FE, chuẩn hóa trước khi validate.
- Serializer: chuẩn hóa output trả về cho FE.
- Validator: rule dùng chung (required, max length, ...).
- Pagination: chuẩn hóa response list.
- Exception handler: chuẩn hóa format error, kèm data request.

6.5 Chuẩn hóa response
- Error format:
  {
    "error": {
      "type": "validation_error | auth_error | not_found | api_error",
      "message": "...",
      "details": { ... }
    },
    "data": { ... }  // payload FE gửi lên
  }
- Pagination:
  {
    "data": [ ... ],
    "meta": {
      "count": 123,
      "page": 1,
      "page_size": 20,
      "next": "...",
      "previous": "..."
    }
  }

6.6 Auth & bảo mật
- Dùng Django auth với custom user:
  - AUTH_USER_MODEL = app_server.User.
  - User kế thừa AbstractUser, thêm field role.
- Có thể bổ sung JWT/Session auth và permission theo role trong giai đoạn tiếp theo.

7) DANH SÁCH USE CASE (NGOÀI CRUD)
- IAM:
  - Đăng ký/đăng nhập (dự kiến dùng Django auth hoặc JWT).
  - Phân quyền theo role (student/teacher/admin).
- CMS/LMS:
  - Tham gia khóa học (gắn course vào user).
  - Theo dõi tiến độ xem video tối thiểu 2 phút.
  - Tính completion và cộng XP khi hoàn thành.
- NFS/SRS/RSE:
  - Tạo session ôn tập.
  - Chọn danh sách card đến hạn.
  - Ghi log review và cập nhật lịch ôn.
- SPS/ACS:
  - Luyện nói theo chủ đề, AI phản hồi theo ngữ cảnh.
  - Lưu transcript và thời gian học cho XP.
- GMS:
  - Tổng hợp XP và hiển thị leaderboard.
- NTS:
  - Nhắc học theo lịch hoặc sau khi bỏ học.

8) SEQUENCE FLOW - ÔN TẬP SRS
- POST /api/rse/review-sessions/ -> tạo ReviewSession
- GET /api/srs/card-srs/?due_date__lte=today -> lấy card đến hạn
- POST /api/rse/card-review-logs/ (choice easy/hard)
- Update CardSRSState (stage, interval_days, due_date)
- PATCH /api/rse/review-sessions/{id}/ set ended_at

9) SEQUENCE FLOW - HOÀN THÀNH LESSON
- Người dùng xem video -> cập nhật watched_seconds.
- Khi đủ min_watch_time -> completed = true, cộng XP.
- Cập nhật lesson_progress và log học tập.

10) SEQUENCE FLOW - SPEAKING
- Client tạo session nói.
- Audio -> STT -> text.
- AI sinh phản hồi theo chủ đề.
- Trả feedback text, ghi log, cộng XP.
