KIẾN TRÚC HỆ THỐNG

Hệ thống được xây dựng theo kiến trúc Modular Monolith.
Các phân hệ được tách theo nghiệp vụ và dùng chung một CORE layer.

Danh sách phân hệ:

CORE (Core System)

IAM (Identity & Access Management)

CMS (Course Management System)

LMS (Learning Management System)

NFS (Note & Flashcard System)

SRS (Spaced Repetition System)

RSE (Review Session Engine)

ACS (AI Chat System)

SPS (Speaking Practice System)

SOC (Social Learning Core)

GMS (Gamification Management System)

NTS (Notification System)

ADM (Admin & Moderation)

PHÂN HỆ CORE (CORE SYSTEM)

CORE là phân hệ nền tảng, cung cấp các thành phần dùng chung cho toàn hệ thống.
Các phân hệ nghiệp vụ sẽ kế thừa và sử dụng CORE để tránh lặp code.

3.1 Mục tiêu của CORE

Chuẩn hóa CRUD

Chuẩn hóa API response

Giảm boilerplate code

Cho phép developer tập trung vào nghiệp vụ chính

3.2 Thành phần chính trong CORE

BaseModel

BaseSerializer

BaseController

CoreRouter

Normalizer

CommonException

Pagination

Permission base

3.3 BaseModel

BaseModel là lớp cha cho toàn bộ model trong hệ thống.

Chức năng:

Tự động có id, created_at, updated_at

Soft delete (is_deleted)

Common query helper

Ví dụ thuộc tính:

id

created_at

updated_at

is_deleted

3.4 BaseSerializer

BaseSerializer là serializer dùng chung.

Chức năng:

Serialize/deserialize dữ liệu

Validate field cơ bản

Cho phép override validate nghiệp vụ

Các serializer cụ thể chỉ cần:

Khai báo model

Khai báo fields

3.5 Normalizer

Normalizer dùng để chuẩn hóa dữ liệu trước khi trả về client.

Chức năng:

Chuẩn hóa format response

Chuẩn hóa lỗi

Convert dữ liệu (date, enum, null)

Ví dụ response chuẩn:
{
"success": true,
"data": ...,
"meta": ...
}

3.6 BaseController (Core Controller)

BaseController cung cấp đầy đủ CRUD API:

list

retrieve

create

update

delete (soft delete)

Các controller nghiệp vụ chỉ cần:

Kế thừa BaseController

Truyền vào:

model

serializer

permission

filter_fields

search_fields

Ví dụ (mô tả logic):

CourseController(BaseController)

model = Course

serializer = CourseSerializer

fields = [...]

3.7 CoreRouter

CoreRouter tự động generate route CRUD cho controller.

Chức năng:

map REST endpoints:
GET /resource
GET /resource/{id}
POST /resource
PUT /resource/{id}
DELETE /resource/{id}

Giúp:

Giảm định nghĩa URL thủ công

Chuẩn hóa API
